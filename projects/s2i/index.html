01

The training loop

S2I is a model-based reinforcement learning method. It builds on a SuperMimic-style world-model learner. The agent collects a small amount of real data and fits a dynamics model. The policy then trains mostly on imagined rollouts. S2I adds a coach that selects the start state of each rollout.

  1. 1 Real data

    The policy runs in Isaac Sim with exploration noise. Only these steps count in the step budget.

  2. 2 World model

    A learned dynamics model predicts the next state and the reward for each action. It trains on real data only.

  3. 3 Coach

    The coach divides the stored states into groups. For each group, it does a trial update and measures the gain in imagined return. It sends more rollouts to the groups with the largest gain.

  4. 4 Imagined rollouts

    The actor and the critic train on 16-step rollouts in the world model. These rollouts cost zero simulator steps.

The updated policy goes back to step 1 and collects new real data.

03

Execution jitter doubles success on the NIST gear board

We add Gaussian noise (σ = 0.3) to the seven arm commands at run time. Training does not change. We wrote the test rules before the test, and we used start states that no earlier test used. A control with only the mean shift from clipping gave no gain. Thus the gain comes from the noise.
